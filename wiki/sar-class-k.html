SAR Class K

A tank locomotive class of the South African Railways, built by the North British Locomotive Company. The archive holds its original builder's drawing set.

Order and builder

  • Seven tank locomotives were ordered under SAR requisition No. 1162, built by the North British Locomotive Co. Ltd., Atlas Works, Glasgow, as contractor's drawings 20654 to 20860 (title block on every sheet: see Set - Original SAR - PDF, files 0001–0045).
  • The SAR Chief Engineer's drawing set is C.E. 8191, indexed as sheets A1 to A185 (index sheet: file 0005; inspector's signature dated 4/7/19(?)).
  • The title blocks print the type in small letters, read as 4-6-4 (tank). Confirm on a clearer sheet.
  • Origin: the Manila Railway. On the motion arrangement sheet (A97, file 0105), the SAR title block is pasted over an older, crossed-out block. That older block names the Manila Railway Company: 3 ft 6 in gauge tank engines with Robinson superheater, built by North British Locomotive Co. It also refers to drawing L 8057 for leading dimensions and valve setting. So the design seems to have been drawn up for Manila first and then taken over for the SAR. Both use 3 ft 6 in gauge.
  • Axle load: 26,880 lb (12 tons) per axle, 6 tons per wheel, from the wheel balancing calculation (A117, file 0127).

Drawing set contents (all 185 sheets read)

The rest of the set covers regulator, safety valves, injectors (Metcalfe's and Gresham), boiler mountings and gauges (A40–A58); clothing and lagging (A59–A65); frames, platforms and cowcatcher (A66–A80); cylinders, valves, motion and reversing gear (A81–A109); lubrication (A110–A113); rods, wheels, axles and axleboxes, springs and compensation (A114–A128); cab, tanks and bunker (A131–A150); sandboxes, buffing and draw gear (A151–A163); brake gear, including vacuum brake (A164–A172); bogie (A173–A178); lamps and tools (A179–A185). Sheet A126 seems to be missing: two files carry A127. The last file in the folder (0198) is not Class K: it's a hand-lettered "Engine & tender weights, Class 14".

The first sheets in detail:

  • General: diagram (A2); general drawing, elevation & plan (A3), end views (A4); pipe arrangement, elevation (A5), plan (A6), end views (A7).
  • Boiler: boiler (A8); boiler stays (A9); longitudinal stay carrier (A10); dome (A11).
  • Firebox: firebox (A12); firebox stay diagram (A13); firebox stays (A14), with copper stays (see Staybolts); bottom ring (A15); brick arch (A16); fittings (A18); firedoor (A19–A22); ashpan (A23–A24); firebars and carriers (A25–A26).
  • Smokebox: smokebox (A27); tubeplate (A28); door (A29); Stone's louvre spark arrester (A30); chimney, blast pipe and exhaust injector pipe (A31); handrail (A32); steam pipe (A33).
  • Superheater: header (A34); elements (A35); details (A36).
  • Draught retarder and blower valve (A37–A39), including the pyrometer pipes (A39).

The full list, with the file for each sheet, is kept in Set - Original SAR - PDF and grows as more title blocks are read.
